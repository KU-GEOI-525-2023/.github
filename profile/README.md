# GEOI 525 - Deep Learning in Remote Sensing

## Welcome to Kathmandu University's Deep Learning in Remote Sensing Course! 🛰️

This organization hosts student projects for the **GEOI 525** minor project course, where we explore the intersection of deep learning and geospatial analysis.

### 🎯 Course Objectives

- Apply deep learning techniques to remote sensing data
- Develop computer vision models for satellite imagery analysis
- Implement geospatial data processing pipelines
- Conduct hands-on projects with real-world remote sensing datasets

### 📚 Topics Covered

- **Convolutional Neural Networks (CNNs)** for image classification
- **Semantic Segmentation** for land cover mapping
- **Object Detection** in satellite imagery
- **Change Detection** using multi-temporal data
- **Time Series Analysis** with remote sensing data
- **Transfer Learning** and pre-trained models

### 🚀 Getting Started

3. Set up your development environment
4. Start working on your minor project
5. Submit your work through pull requests
