# Support

## Getting Help with GEOI 525

If you need help with the Deep Learning in Remote Sensing course, here are several ways to get support:

### 📚 Documentation

1. **Course Materials**: Check the course repository for lectures, tutorials, and examples
2. **README Files**: Each project repository has a README with setup instructions
3. **Contributing Guide**: Review [CONTRIBUTING.md](CONTRIBUTING.md) for project guidelines
4. **Code of Conduct**: Familiarize yourself with our [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)

### 💬 Ask Questions

#### GitHub Issues
- Use the [Question template](.github/ISSUE_TEMPLATE/question.yml) to ask questions
- Search existing issues first to see if your question was already answered
- Tag your issue with appropriate labels
- Provide context and code samples when relevant

#### GitHub Discussions
- Join community discussions for broader topics
- Share ideas and best practices
- Help other students

### 🐛 Report Bugs

If you find a bug in course materials or sample code:
1. Use the [Bug Report template](.github/ISSUE_TEMPLATE/bug-report.yml)
2. Include detailed steps to reproduce
3. Provide error messages and logs
4. Share your environment details

### 📋 Submit Projects

When submitting your project:
1. Use the [Project Submission template](.github/ISSUE_TEMPLATE/project-submission.yml)
2. Ensure all checklist items are completed
3. Include comprehensive documentation
4. Provide clear visualizations of results

### 🎓 Contact Instructors

For course-specific questions:
- **Office Hours**: Attend scheduled office hours
- **Email**: Contact course instructors (check course syllabus)
- **In-Person**: Visit during designated times

### 🤝 Peer Support

- Form study groups with classmates
- Review each other's code through pull requests
- Share resources and learning materials
- Collaborate while maintaining academic integrity

### ⚡ Quick Tips

1. **Before asking**: Search for similar questions/issues
2. **Be specific**: Provide context, code, and error messages
3. **Be patient**: Instructors and peers may need time to respond
4. **Be respectful**: Follow the Code of Conduct
5. **Give back**: Help others when you can

### 🚨 Emergency Situations

For urgent technical issues during deadlines:
- Check course announcement channels
- Contact instructors immediately
- Document the issue with screenshots/logs

**Remember**: Everyone is here to learn. Don't hesitate to ask questions, and help create a supportive learning environment for all!
