# Deep Learning in Remote Sensing - GEOI 525

This repository contains community health files and project guidelines for the Deep Learning in Remote Sensing (GEOI 525) course at Kathmandu University.

## About the Course

GEOI 525 is a minor project course focusing on applying deep learning techniques to remote sensing data and geospatial analysis.

## Repository Structure

This `.github` repository provides:
- Default community health files for all repositories in the organization
- Issue templates for project submissions and questions
- Pull request templates for code reviews
- Contributing guidelines for students
- GitHub Actions workflows for automated testing

## Resources

For course-specific projects and assignments, please refer to the individual repositories within the organization.

## Getting Started

1. Review the [Contributing Guidelines](CONTRIBUTING.md)
2. Familiarize yourself with the [Code of Conduct](CODE_OF_CONDUCT.md)
3. Use issue templates when creating new issues
4. Follow the pull request template when submitting your work

## Contact

For questions about the course, please contact your instructor or use the issue tracker in the appropriate repository.
